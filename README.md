# Hadoop-Single-Node
Hadoop Single Node Deployment Script 

Automated Hadoop Single-Node and Multi-Node Cluster Deployment Scripts for Linux, simplifying Hadoop configuration, HDFS/YARN setup, service initialization, and distributed cluster administration.


This repository contains Bash automation scripts for deploying Apache Hadoop in both single-node and multi-node environments. The scripts automate Hadoop configuration, HDFS and YARN setup, service initialization, and basic cluster deployment tasks on Linux systems.

The project provides practical experience with Hadoop administration, Linux, Bash scripting, SSH, HDFS, YARN, distributed systems, and multi-node cluster configuration.
